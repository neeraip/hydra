# Plans

Design notes for work that is neither scheduled nor committed: what was
found, what it would take, and what has to be true before it is worth
starting.

**Not published.** The documentation site builds from `docs/src` only, so
nothing here reaches a reader of the book. That is deliberate: these
describe capabilities Hydra does not have, and a docs site that describes
them is a docs site that lies.

A plan here is a record, not a promise. Each states its own revisit
trigger; when one fires, the plan is re-read against what changed and
either becomes work or is deleted.
