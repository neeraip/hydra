# hydra-engine-och

Hydra's open-channel hydraulics simulation engine. **Early scaffold — not yet functional.** The
crate is published so its name and versioning track the Hydra workspace
from the start; see [hydra-sdk](https://crates.io/crates/hydra-sdk) for
the current Hydra library. Development happens at
<https://github.com/neeraip/hydra>.
