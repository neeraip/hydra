Hydra

The browser demo

Try Hydra

The real engines, compiled to WebAssembly. Nothing is uploaded. The model is read, solved and reported here.

Drop a model here, or click to choose one.

An EPANET or SWMM .inp file. Drop auxiliary files (climate, hotstart saved as version 3 or later, routing inflows) alongside it and they will be matched by name.

No model on hand? Try one of these:
hydra run … 

      

    


    

      

        The report above is the engine's own summary: the same bytes
        hydra run model.inp writes to stdout. Coloured lines
        are the diagnostics it writes to stderr, shown readably. Models are
        read, solved and reported in this tab; nothing is uploaded anywhere.
      

      

        Browser limits apply. Everything here lives in this
        tab's memory, which browsers cap (a hard 4 GB ceiling, in practice
        far less). Capturing .out results for a large network
        can exhaust it. The desktop app, the CLI, and the Rust SDK stream
        results from disk and have no such limit: treat this page as a way
        to try Hydra, and run large models natively.
